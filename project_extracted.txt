Individual charge results
For each non-coincident charge, print its charge identifier, Ex, Ey, magnitude, and angle. Apply the same counterclockwise angle and undefined-angle rules stated above. Print the resultant charge-only components, magnitude, and angle separately.
Charge coincident with the reference point
A point charge’s field is undefined at its own coordinates. Follow the project convention by excluding a charge only when its coordinates exactly match the current reference point. Print a clear line such as:
Charge 2: skipped because it coincides with the reference point; its field is undefined here.
Calculate the charge-only result from the remaining charges and state how many were excluded. If all charges are excluded, report that the displayed zero is the sum from zero included charges under this project convention; do not imply the physical field at the coincident point is zero. This exclusion rule applies to field evaluation at that point only. Do not exclude that charge from output 4.
Reference-point changes and background-field behavior
Changing the reference point updates the working reference point and requires recalculating every charge’s field from the original charge data. An active uniform background field remains active because it is uniform. Add it once to the newly calculated charge-field resultant.
Treat the background-field action as setting or replacing one active background field, not accumulating repeated copies. Entering a magnitude of zero removes the active background field. Show the charge-only result and, when a background field is active, the net result separately.
Air model, units, and constants
Model the project’s medium as dry, carbon-dioxide-free air at 20 °C and 101.325 kPa. Use these fixed approximations:
(\varepsilon_0 = 8.8541878188 \times 10^{-12}\ \mathrm{F/m})
(\varepsilon_{r,\text{air}} = 1.0005364)
(k_{\text{air}} = 1/(4\pi\varepsilon_0\varepsilon_{r,\text{air}}) \approx 8.9827 \times 10^9\ \mathrm{N,m^2/C^2})
Convert charge once: q_C = q_microC × 1e-6
Convert degrees to radians using radians = degrees × PI / 180, with a portable PI definition rather than relying on a compiler-specific constant.
For a charge (q) at ((x_q,y_q)), calculate its field at ((x,y)) using:
E = k_air × q_C × (dx, dy) / r³
where dx = x - xq, dy = y - yq, and r = sqrt(dx² + dy²). Do not evaluate this formula when r is zero; apply the coincident-charge rule instead.
Output 4: nearest distance to the target-field location
Output 4 uses one selected, nonzero point charge and excludes the background field. The target field is a nonnegative magnitude in N/C. For a positive target (E_t), calculate the radius of the target-field circle around the selected charge:
target_radius = sqrt(k_air × abs(q_C) / E_t)
Let d be the distance from the charge to the current reference point. Report:
shortest_distance = abs(d - target_radius)
This is the shortest distance from the reference point to any location where the selected charge’s field magnitude equals the target. If the reference point is at the charge, the shortest distance is the target radius; no unique direction exists, but the distance is still defined. If the reference point lies on the target-field circle, report zero. If a closest point is displayed and the reference point is not at the charge, it lies on the line between the charge and reference point.
A negative target field is invalid. A zero target field has no finite matching location for a nonzero point charge. A zero charge cannot produce a positive target field.
