4. Main Functionality of Module 2
After receiving the information from Module 1, Module 2 should calculate the electric field at the initial reference point.
For every available charge, calculate:
Electric field X-component (Ex).
Electric field Y-component (Ey).
Electric field magnitude.
Electric field direction.
After calculating individual contributions, calculate the resultant electric field due to all charges.
Use the following equations.
Electric field due to an individual charge
Let:
q = charge in Coulombs.
(xq, yq) = charge coordinates.
(x, y) = reference point.
k = Coulomb's constant for the project's dry-air approximation.
First calculate:
dx = x - xq
dy = y - yq
r = sqrt(dx² + dy²)
Then:
Ex = k × q × dx / r³
Ey = k × q × dy / r³
Electric field magnitude:
E = sqrt(Ex² + Ey²)
Constants and units
Use these project constants:
Vacuum permittivity: 8.8541878188 × 10⁻¹² F/m
Relative permittivity of air: 1.0005364
Pi: 3.14159265358979323846
Calculate:
k = 1 / (4 × pi × epsilon0 × epsilon_r_air)
Charge values received in microcoulombs must be converted into Coulombs before calculations.
Coordinates and distances must be in metres.
Electric field values must be in N/C.
Preserve the positive or negative sign of each charge.
Resultant electric field
Calculate:
Ex_total = Sum of all individual Ex values
Ey_total = Sum of all individual Ey values
E_total = sqrt(Ex_total² + Ey_total²)
Calculate the direction using both components so that the correct quadrant is obtained.
Angles must be measured counterclockwise from the positive X-axis and displayed between 0° and 360°.
Special cases:
Positive Y-axis: 90°.
Negative Y-axis: 270°.
Zero electric field: angle is undefined.
Never display 90° automatically whenever Ex is zero.
5. Handle Coincident Charges
A charge may be located exactly at the reference point.
In that situation, its electric field is undefined.
Handle this condition safely:
Do not divide by zero.
Skip that charge only for the current field calculation.
Display a short message explaining why it was skipped.
Continue calculating the contributions of other charges.
Show the number of skipped charges.
Do not delete or modify the original charge information.
If every charge is coincident with the reference point, display the zero sum over the included charges and clearly explain that the physical electric field is undefined at that point.
6. Follow-up Menu
After displaying the initial results, show the following menu:
Change Reference Point
Set / Change / Clear Background Electric Field
Find Shortest Distance for a Target Electric Field (Output 4)
Exit
Allow the user to perform multiple operations until they select Exit.
Option 1 – Change Reference Point
Ask for the new X-coordinate.
Ask for the new Y-coordinate.
Recalculate the electric field using the original Module 1 charge information.
Display the updated individual fields and resultant field.
Do not modify the original charge coordinates.
Do not reuse previous calculation results.
Option 2 – Uniform Background Electric Field
Allow the user to add a uniform background electric field.
Ask for:
Background field magnitude in N/C.
Direction in degrees, measured counterclockwise from the positive X-axis.
Calculate:
Ex_bg = E_bg × cos(theta)
Ey_bg = E_bg × sin(theta)
Display the background field components separately.
Calculate the net electric field:
Ex_net = Ex_total + Ex_bg
Ey_net = Ey_total + Ey_bg
E_net = sqrt(Ex_net² + Ey_net²)
Requirements:
The background field must remain active after changing the reference point.
Setting a new background field must replace the previous one.
Entering zero magnitude must clear the background field.
Do not add the background field more than once.
Do not include the background field in Output 4.
Option 3 – Output 4: Shortest Distance
This feature calculates the shortest distance from the current reference point to a location where the electric field magnitude due to one selected charge equals the target electric field.
Use only one nonzero charge from Module 1.
Do not ask the user to enter charge values or charge coordinates again.
If multiple nonzero charges are available, display their IDs and allow the user to select one.
For the selected charge:
target_radius = sqrt(k × abs(q) / E_target)
Calculate the distance between the reference point and the selected charge:
d = sqrt((xr - xq)² + (yr - yq)²)
Shortest distance:
shortest_distance = abs(d - target_radius)
Display the shortest distance in metres.
Special conditions:
Negative target magnitude: reject it and ask again.
Zero target magnitude: explain that no finite matching location exists.
If the reference point is already on the target circle, the shortest distance is zero.
If the reference point is at the charge location, the shortest distance equals the target radius.
If no nonzero charge is available, explain that Output 4 cannot be performed.
The background electric field must not affect this calculation.
